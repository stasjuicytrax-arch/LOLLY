# LOLLY — Дизайн-система EPK

Источник: `docs/references/ref-1.jpg` (Netflix/O'Brien — тёмный, кинематографичный, микротипографика), `ref-8.jpg` (Reload — красная монохромия, огромные капсы, картинки-«пилюли» внутри строк), `ref-23.jpg` (Folioblox — тёплый градиент, скруглённые контейнеры, чёткая иерархия) + фото артиста (`hero-4-main.jpg` — красный циклорама-фон).

Обязательно: перед вёрсткой прогнать эту систему через скиллы **impeccable** (`/impeccable init`, затем `/impeccable document` → сверить с этим файлом) и **taste-skill** (`design-taste-frontend`). При конфликте — побеждает этот файл, если правило скилла не про «AI slop».

## 1. Настроение

**«Красный свет клуба в 3 часа ночи».** Кино, а не лендинг. Почти чёрная сцена, на которой единственный источник света — красный. Артист — героиня постера, текст — титры.

Три слова: **кинематографично · громко · точно.**
Чего НЕ должно быть: неон-радуги, «киберпанк-глитч» на всём подряд, стоковые эквалайзеры, иконки нот, градиенты фиолетовый→розовый, бежевые «AI»-палитры, карточки в карточках.

## 2. Цвет

Монохромная красная система. Один акцент, всё остальное — тон.

| Токен | HEX | Где |
|---|---|---|
| `--ink` | `#0B0505` | основной фон (тёплый, не чистый #000) |
| `--ink-2` | `#160606` | поднятые плоскости, футер |
| `--blood` | `#360405` | глубокие тени, фон секций-переходов |
| `--wine` | `#8B1B17` | тени красного, hover-заливки |
| `--signal` | `#E3150F` | ГЛАВНЫЙ акцент: ключевые слова, CTA, курсор, линии прогресса |
| `--studio` | `#B63D34` | цвет циклорамы hero-фото — мост между фото и фоном |
| `--bone` | `#F0EDEC` | основной текст, светлые секции-вставки |
| `--ash` | `#C6A29D` | вторичный текст на тёмном, «приглушённые» слова в заголовках |
| `--smoke` | `rgba(240,237,236,.08)` | разделители, бордеры 1px |

Правила:
- Доля цвета на экране: 70% ink / 20% red-тона (фото + градиенты) / 10% bone. `--signal` — не больше 3–5% площади.
- Приём ref-8: в больших заголовках часть слов — `--bone`, часть — `--ash` (две «громкости» в одной фразе).
- Одна светлая секция-«вспышка» (`--bone` фон, `--blood` текст) на весь сайт — для манифеста/статистики. Создаёт ритм «темно-СВЕТ-темно».
- Красное свечение — только радиальными градиентами `radial-gradient(60% 50% at 50% 40%, rgba(227,21,15,.35), transparent)` за объектами, как свет прожектора. Никаких box-shadow-glow на кнопках.
- Логотип: белый (`lolly-logo-white.png`) на тёмном, чёрный — на `--bone`.

## 3. Типографика

Логотип LOLLY — кастомный «металл-готик» с леденцом-спиралью. Шрифтами его **не имитируем**, только PNG/SVG. Типографика сайта — строгий гротеск, контраст с логотипом.

| Роль | Шрифт | Настройки |
|---|---|---|
| Display | **Archivo** (Google, variable: `wdth 62–125`, `wght 100–900`) | капс, `wght 700–800`, `letter-spacing: -0.04em`, `line-height: .86` |
| Text / UI | **Geist** | `400/500`, `line-height 1.5`, `letter-spacing -0.01em` |
| Micro / метки | **Geist Mono** | `11–12px`, капс, `letter-spacing .08em` |

Variable-ось `wdth` — главный «моторный» приём: заголовки дышат шириной на скролле / hover (62 → 100 → 125), как звук, растягивающийся на дропе.

Шкала (fluid, `clamp`):
- `--fs-mega`: `clamp(5rem, 22vw, 26rem)` — слово LOLLY / цифры статистики
- `--fs-h1`: `clamp(3rem, 9vw, 9rem)`
- `--fs-h2`: `clamp(2.25rem, 5.5vw, 5.5rem)`
- `--fs-h3`: `clamp(1.5rem, 2.4vw, 2.25rem)`
- `--fs-body`: `clamp(1rem, 1.1vw, 1.125rem)`
- `--fs-micro`: `0.75rem`

Правила:
- Заголовки — капс, тесный трекинг, переносы руками (как в ref-8: ступенчатые строки со сдвигом отступа).
- Body-текст — максимум 60 символов в строке, никогда не центрировать абзацы длиннее 2 строк.
- Микро-метки в углах блоков (ref-1): `[ 02 ] RESIDENCIES`, `YGN — BKK`, `EST. 2015`. Это «титры» сайта.
- Запрещено: italic-serif акценты, градиентный текст, обводка текста как основной приём (допустимо 1 раз — фоновое гигантское слово outline).

## 4. Сетка

- Desktop ≥1280: 12 колонок, поле `clamp(20px, 4vw, 64px)`, gutter `24px`, max-width контента `1680px`; фото/видео могут выходить в full-bleed.
- Tablet 768–1279: 8 колонок, gutter 20px.
- Mobile <768: 4 колонки, поле 16px, gutter 12px.
- Асимметрия обязательна: текст 5 колонок + медиа 6 со смещением на 1, а не 6/6. Ступенчатые заголовки начинаются с разных колонок (1 → 3 → 5).
- Вертикальный baseline: 8px.

## 5. Пространство и ритм блоков

Шкала отступов: `4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128 · 192 · 256`.

- Между секциями: `clamp(128px, 18vh, 256px)`. Воздух — это дорого.
- Внутри секции: метка → заголовок 32px → текст 24px → медиа 64–96px.
- Ритм страницы — чередование плотности: **ГРОМКО (full-bleed медиа) → тихо (текст, воздух) → ГРОМКО → данные (списки) → вспышка (светлая секция) → ГРОМКО → тихо (контакт)**.
- Каждый экран держит один главный объект. Если на экране два «героя» — один лишний.
- Скругления: медиа-карточки `20px` (ref-23/ref-8), пилюли/кнопки `999px`, крупные секции-контейнеры `32px` только по нижним углам (ref-23, переход hero → контент). Плоские элементы данных (списки клубов) — без скруглений и без карточек, просто линии 1px `--smoke`.

## 6. Компоненты

- **Кнопка-пилюля**: обводка 1px `--bone`, текст Geist Mono капс, справа кружок со стрелкой `↗`. Hover: заливка `--signal` растекается из точки курсора, стрелка уезжает и возвращается.
- **Пилюля-картинка в строке заголовка** (ref-8): между словами вставлен овал 2.2em × 1em с фото/видео-лупом артиста. Минимум 2 раза на сайте.
- **Метка-титр**: `[ 03 ]` + название, Geist Mono, `--ash`.
- **Строка списка** (клубы, резидентства): название слева, город/год справа моно, линия снизу; hover — строка подсвечивается `--signal`, рядом с курсором появляется превью-фото/видео.
- **Счётчик**: мега-цифра Archivo `wdth 62` + подпись моно.
- **Медиа-карточка**: скругление 20px, внутри видео-луп muted, подпись в нижнем левом углу, кнопка Play в правом нижнем.
- **Кастомный курсор** (desktop): точка 8px `--signal`, над медиа превращается в круг 80px с текстом `PLAY` / `VIEW` / `DRAG`.

## 7. Анимация (motion-система)

Библиотеки: **GSAP + ScrollTrigger + SplitText**, **Lenis** (smooth-scroll). Опционально: WebGL-шейдер (OGL/three) для hero.

Easing: `--ease-out: cubic-bezier(.16,1,.3,1)` (expo-out) — основной; `--ease-io: cubic-bezier(.76,0,.24,1)` — для шторок/переходов.
Длительности: micro 200ms · ui 450ms · reveal 900ms · cinematic 1400ms. Stagger: 40–60ms по символам, 80ms по строкам.

Главные ходы:
1. **Прелоадер — вращающаяся спираль-леденец** из логотипа + счётчик 000→100, затем шторка уходит вверх красной плоскостью.
2. **Маск-reveal заголовков**: строки выезжают снизу из-под маски (SplitText lines), не fade.
3. **Variable-width «дыхание»**: заголовки меняют `wdth` от скорости скролла (velocity-mapped).
4. **Pinned-сцены**: таймлайн резидентств — горизонтальный скролл при вертикальной прокрутке.
5. **Clip-path раскрытие медиа**: видео раскрывается из пилюли в full-bleed на скролле (`clip-path: inset(...) round ...`).
6. **Marquee жанров** с ускорением от скорости скролла и сменой направления.
7. **Hover-превью** в списках клубов: картинка следует за курсором с инерцией.
8. **Магнитные кнопки** (лёгкие, ≤12px смещения).
9. **Grain-оверлей** (SVG-noise, opacity .06, анимирован steps) поверх всего — плёночная фактура.

Ограничения: `prefers-reduced-motion` — отключаем pin, scrub, marquee, оставляем простые fade. Никаких pulse-точек, bounce, вращающихся без смысла иконок. 60fps: анимируем только `transform`, `opacity`, `clip-path`, `font-variation-settings`.

## 8. Фото и видео

- Цветокор единый: тени в бордо, подъём красного канала. Фото на белом фоне (press-01…08) в тёмных секциях — через `mix-blend-mode: multiply` на красной плашке ИЛИ дуотон ink/signal; в галерее — оригинал.
- Видео — всегда muted autoplay loop (`*-loop.mp4`) в превью, полная версия со звуком — в лайтбоксе.
- Grain и виньетка поверх видео; `assets/img/fx/gradient-mask-vertical.png` — маска затемнения верх/низ для вертикальных кадров.

## 9. Чек-лист «не slop»

- [ ] Нет Inter / Roboto / системного шрифта
- [ ] Нет эмодзи и стоковых иконок нот/наушников
- [ ] Нет одинаковых карточек 3-в-ряд как основного паттерна
- [ ] Нет «eyebrow-чипсов» над каждым заголовком
- [ ] Нет фиолетовых градиентов и glow-теней
- [ ] Каждая секция отличается композицией от соседней
- [ ] Прогнан `/impeccable audit` и `/impeccable polish`
